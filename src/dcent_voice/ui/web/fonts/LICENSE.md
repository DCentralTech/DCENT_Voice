# Bundled fonts

The `.woff2` files in this directory are the unmodified Latin-subset bytes
served by Google Fonts at the exact upstream URLs below. Google Fonts performed
the format/subset production; DCENT_Voice only renamed the downloaded files for
stable offline references and did not alter their font tables or glyph data.
They are redistributed under the **SIL Open Font License 1.1**. The complete
governing text is bundled as [`OFL-1.1.txt`](OFL-1.1.txt).

| Font | Files | Copyright and canonical source | Google Fonts snapshot |
|------|-------|--------------------------------|-----------------------|
| Barlow Condensed | `barlowcondensed-600.woff2`, `barlowcondensed-700.woff2` | Copyright 2017 The Barlow Project Authors; <https://github.com/jpt/barlow> | <https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B4873z3bWuQ.woff2> (600), <https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B46r2z3bWuQ.woff2> (700) |
| Inter | `inter-400.woff2` through `inter-700.woff2` (the same variable Latin-subset bytes) | Copyright (c) 2016 The Inter Project Authors; <https://github.com/rsms/inter> | <https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2> |
| JetBrains Mono | `jetbrainsmono-400.woff2`, `jetbrainsmono-600.woff2` (the same variable Latin-subset bytes) | Copyright 2020 The JetBrains Mono Project Authors; <https://github.com/JetBrains/JetBrainsMono> | <https://fonts.gstatic.com/s/jetbrainsmono/v24/tDbv2o-flEEny0FZhsfKu5WU4zr3E_BX0PnT8RD8yKwBNntkaToggR7BYRbKPxDcwg.woff2> |

The three upstream OFL copyright headers specify no Reserved Font Names.
Because these are upstream-produced subset files rather than a DCENT-created
modified font, the original family names are retained. Even if the upstream
subsetting is treated as modification, retaining those names does not conflict
with an RFN declaration because none is present.

These fonts are used only for the DCENT_Voice UI. They are not part of the
MIT-licensed application source and retain their own OFL license.
