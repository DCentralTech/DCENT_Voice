How to dictate

Ctrl+Win · speak · release

Text lands in the app you were using. No extra window.

English is the default. Auto and More languages stay on the same local model for French, German, Spanish, and 22 other European languages. Mixed speech still decodes locally. Japanese, Chinese, Korean, Arabic, and Hindi use a same-size fallback — never a giant model.

Auto Cleanup and Writing style run on-device after transcription. High is local hedge trimming, not a cloud rewrite. Optional Ollama/LM Studio cleanup stays under Advanced.

Destination styles by app

Same speech, different destination. The built-in map covers Outlook→Email, Slack/Teams→Chat, VS Code/terminals→Code, and Notion/Obsidian/OneNote→Notes. Your locally stored overrides take priority.

Profiles, live dictation, Command, and local API

Per-app injection

Optional local AI cleanup

On-device tone (email / chat / formal) is always local and needs no model. This toggle asks a running Ollama or LM Studio model to polish further. If that model is down, dictation still inserts the heuristic text. Never required. Never silent cloud.

Modes

One hotkey is enough: hold dictation, speak, release. Other modes are optional.

Dictation

Recommended

Hold your dictation hotkey, speak, then release. DCENT_Voice transcribes the complete recording and inserts it into the app you were using.

Best for everyday writing. The full recording is available before text is inserted, so recognition is more reliable than Live Dictation. Auto Cleanup (None / Light / Medium / High) and Writing style (email, chat, code, formal, notes) run on-device after transcription — no network and no LLM required. Optional local AI cleanup stays under Advanced.

Live Dictation

Advanced

Hold your live dictation hotkey to insert stable words while you are still speaking.

Stable words type while you speak. Spoken edits like scratch that retract on release (Backspace). A rare mid-stream mis-hear can still appear briefly before finalize. Prefer regular Dictation when accuracy matters most.

Command

Optional

Hold your command hotkey and describe an action.

  • Text selected: your command rewrites or replaces that selection.
  • Nothing selected: the result is inserted at the cursor.
  • App or tool action: DCENT_ADE must be running and connected.

Offline transforms work without an LLM: formalize, uppercase/lowercase/title/sentence case, bullet or numbered list, snake/camel/kebab/constant case, quote, parentheses, fix spacing, shorten, reverse. A local cleanup LLM still helps for free-form rewrites.

Spoken edits & polish

Local

While dictating, speak structure instead of typing it:

  • scratch that · replace X with Y · no I meant … — natural corrections
  • scratch that / undo that alone — retract the last insert
  • email style · as notes · in code style — this utterance only, local styles
  • cleanup high · no cleanup — this utterance only, local Auto Cleanup
  • press enter — insert the rest, then send Enter (chat / prompt boxes)
  • my email · my calendar · my signature — fill the expansion once, then say the cue
  • Import JSON — load a local snippet file; nothing is synced off this machine
  • new line · new sentence · bullet — structure and lists
  • comma · full stop · question mark — punctuation by voice
  • dot py · vs code · git status — developer spoken forms

Auto Cleanup and Writing style live on General. Names, brands, jargon, snippets, and fine polish toggles live under Dictionary.

Personal dictionary

          
Use the dictionary for names, product terms, and phrases recognition often gets wrong. Enter what you say and the exact written form you want; cues can be up to 60 characters and corrections up to 4,000. Everything stays on this machine. Search and Starred only control which rows you export or remove, and starred entries receive dictation priority. CSV imports are reviewed before they change anything and can be undone.
