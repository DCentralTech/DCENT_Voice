Transcription profile and model storage
03

Transcription profile

Offline model storage

The complete DCENT_Voice package includes the verified local speech model and its offline fallback. Dictation never downloads a speech model at runtime and never uploads microphone audio on a local profile. If either model is missing or corrupt, reinstall the complete package or provision the pinned offline bundle.

To choose a different balance of speed, accuracy, and resource use, open Settings → Models.

04

Choose the right mode

Dictation Recommended

Records the complete phrase, then transcribes and inserts it. Start here for the most dependable everyday writing.

Live Dictation Advanced

Inserts stable words while you speak. On release, spoken edits like “scratch that” retract already-typed text. A rare mid-stream mis-hear can still flash briefly before finalize.

Command Optional

With text selected, your spoken command rewrites that selection. With nothing selected, the result is inserted at the cursor. Rich commands need a running LLM; app/tool actions also need DCENT_ADE.
